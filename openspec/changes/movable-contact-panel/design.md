# 展示控制器

floating_panel.js 独立管理 Pointer Events 和布局存储，不读取会话或调用发送函数。first_contact.js 保留原有控件 ID 和发送逻辑，仅包裹标题栏、正文及小按钮。

移动超过 5 CSS 像素才视为拖动；拖动后抑制紧接着的鼠标点击，小幅移动仍为点击，键盘点击仍能展开。标题栏中的按钮/链接不作为拖动入口。指针取消或窗口失焦结束拖动。坐标限制在视口内，窗口调整后重新限位。

chrome.storage.local 只保存 x、y、collapsed 三项界面偏好。存储错误不影响发送；异步恢复不能覆盖已经发生的用户交互。收起面板不移除原来的控件，不停止消息监听，也不自动发送。
