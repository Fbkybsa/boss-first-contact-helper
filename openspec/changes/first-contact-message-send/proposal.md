# 首次接触消息页一键沟通

## Why

原扩展把 JD 评分、自动建立会话、统计和发送串在一起，当前链路无法可靠使用。本次降级只保留用户手动筛选岗位、手动打招呼之后的消息页发送。

## What Changes

- 投递页在用户手动发出招呼后，只自动处理“已向BOSS发送消息”弹窗中的“留在此页”。
- 扩展在另一个 BOSS 消息页窗口监听列表顶部新增的聊天窗口，自动点开并判断自己是否只发出过首条打招呼文字；对方回复不取消首次接触资格。
- 消息页面板提供“发送图片和文字”“仅发图片”“仅发文字”三个手动按钮；已有沟通或已有发送尝试时仍允许用户按当前需要补发。
- 判断通过后，依次发送现有设置中的简历图片和话术；每一步都核对当前会话与消息流。
- 自动判断不明、会话切换、发送结果不明或平台验证时停止，并给出可见原因。自动尝试不重放。
- **BREAKING**：当前扩展清单不再加载 JD 评分、自动点击“立即沟通”和投递统计流程。

## Capabilities

### New Capabilities

- `first-contact-send`: 用户在消息页对首次接触会话自动发送简历图片和话术，也可手动发送整套内容或单独补发图片/文字，并对不确定结果停止发送。
- `stay-on-page`: 用户手动建立沟通后，在投递页自动选择留在当前页，同时让消息页窗口继续监听。

### Modified Capabilities

无现有 OpenSpec 能力文件；旧版需求记录在 `docs/`。

## Impact

- 扩展入口与弹出页文案调整；沿用本地服务的设置和简历图片接口。
- 增加独立的首次接触判断与发送流程，以及 Node 内置单元测试。
