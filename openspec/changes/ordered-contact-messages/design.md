# 顺序与兼容

advantage_messages 为有序数组，服务端校验 1–3 个非空字符串，每个最多 300 字符。advantage_message 保留为首段镜像；老配置自动回退为一段，老客户端编辑首段不清空后续段落。两个设置入口均提供三框，空的可选框在提交前跳过。

图片仍先发送并确认，文字仍最后呈现。固定短序列采用原生 async/await 串行循环；已搜索参考 p-queue，不引入通用排队依赖。每段发送前确认目标和本人已发消息顺序；每次文字确认后、继续下一段前再次核对，平台图片 ID 更新不作为新增内容判据。

收到对方回复不打断；自己额外发送或切换会话则停止。发送结果未确认时保留可能已发出的提示，不自动重发、不猜测续发点。仅发图片不验证文字配置，整组发送与仅发文字复用同一顺序流程。
