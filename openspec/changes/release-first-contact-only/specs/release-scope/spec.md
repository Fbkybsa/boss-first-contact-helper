# 发布范围

## ADDED Requirements

### Requirement: 只分发已选定的功能

发布版 SHALL 不分发匹配打分实现、模型配置与调用入口、分数字段及评分展示；SHALL 保留图片/文字发送和岗位记录。

#### Scenario: 未验证接口不可调用

- **WHEN** 客户端请求未包含在发布范围内的评分接口
- **THEN** 服务返回 404，且不发起模型请求

#### Scenario: 配置只包含发送材料

- **WHEN** 使用者读取、更新发送配置
- **THEN** 仅提供图片与个人优势配置，拒绝额外字段，旧配置中额外字段不被读取或重新保存

#### Scenario: 岗位记录继续可用

- **WHEN** 网页建立沟通并提交岗位快照
- **THEN** 保存 JD、公司、薪资和 HR 记录，并可查询及导出；无需任何评分字段
